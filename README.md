# akshatkarani.github.io

Source for [akshatkarani.github.io](https://akshatkarani.github.io). It is a plain Jekyll site with no theme and no
JavaScript, built and deployed by GitHub Pages from the `master` branch.

## Layout

| Path                    | What it is                                         |
| ----------------------- | -------------------------------------------------- |
| `index.html`            | Home page: intro, journey scrubber, experience, skills, list of posts |
| `_posts/`               | Blog posts (Markdown)                              |
| `_layouts/`, `_includes/` | Page templates                                   |
| `assets/css/main.css`   | All styles (light + dark via `prefers-color-scheme`) |
| `_data/profile.yml`     | Name, title, links, roles, skills: generated by `resume/sync.py` from `resume/profile.yml`, don't edit by hand |
| `_config.yml`           | Site metadata (tagline/description also written by `sync.py`) |

## Writing a post

Create `_posts/YYYY-MM-DD-slug.md`:

```markdown
---
title: "Post title"
description: "One-sentence summary, used for previews and SEO."
---

Post body…
```

Posts appear on the home page automatically. Posts tagged `GSoC` are grouped under the GSoC 2019 series.

## Running locally

With Ruby installed:

```sh
bundle install
bundle exec jekyll serve --livereload   # then open http://localhost:4000
```

Or with Docker (no Ruby needed; gems are cached in `~/.cache/jekyll-bundle` so only the first run downloads them):

```sh
mkdir -p ~/.cache/jekyll-bundle
docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp -e BUNDLE_PATH=/bundle -e BUNDLE_APP_CONFIG=/tmp/bundle-config \
  -v ~/.cache/jekyll-bundle:/bundle -v "$PWD":/srv/jekyll -w /srv/jekyll ruby:3.3 \
  sh -c "bundle install --quiet && bundle exec jekyll build"
cd _site && python3 -m http.server 4173   # then open http://127.0.0.1:4173/
```

The page uses root-relative asset paths, so serve `_site` over HTTP rather than opening `index.html` directly.
